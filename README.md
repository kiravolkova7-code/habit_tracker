# Habit Tracker
Современное веб-приложение для отслеживания полезных привычек, построенное на микросервисной архитектуре. 
Сервис помогает пользователям формировать рутину, фиксировать ежедневные успехи и визуализировать прогресс 
с помощью календаря регулярных действий.

## Описание
Вся инфраструктура контейнеризована: приложение, база данных, брокер сообщений `Redis` и обратный прокси `Nginx` 
запускаются одной командой благодаря настроенному `Docker Compose`. 

Разработка ведется с применением практик `CI/CD`: пайплайны автоматически проверяют стиль кода, прогоняют тесты
и собирают образы перед каждым слиянием изменений в ветку `main`.

## Функционал
* Управление привычками: создание, редактирование и удаление пользовательских задач с указанием названия, иконки и 
целевой частоты выполнения.
* Отметка прогресса: удобный календарь для фиксации выполненных дней в один клик.
* Визуализация статистики: отображение текущих серий (стеков), процента выполнения за месяц и тепловой карты активности.
* Аутентификация пользователей: регистрация, вход в аккаунт и безопасное восстановление доступа через JWT-токены.
* Контейнеризация:
Полная изоляция сервисов (`Backend`, `DB`, `Cache`,`Proxy`) с помощью `docker-compose.yml`.
Настройка обратного прокси-сервера `Nginx` для маршрутизации запросов, сжатия трафика и раздачи статики.
* Автоматизация:
Пайплайны `CI/CD` (`GitHub Actions`) для линтинга (`black`, `ruff`), проверки типов (`mypy`) и запуска тестов (`pytest`).
Автоматическая сборка и пуш `Docker`-образов в реестр при успешном прохождении проверок.

## Зависимости 
* Язык: `Python 3.14`
* Фреймворк: `Django 6.0.7`, `Django REST Framework`
* База данных: `PostgreSQL 16.14`
* Кэш/Очередь: `Redis 8.x`
* Задачи: `Celery 5.6.3` + `django-celery-beat`
* Инфраструктура: `Docker`, `Docker Compose v3.9`

(Полный список пакетов находится в вашем файле `requirements.txt`)

## Тестирование
Для обеспечения качества кода используются:

* `Unit`-тесты стандартной библиотеки `Django` (`python manage.py test`).
* Статический анализатор `Flake8` (указан в зависимостях).
* Покрытие тестами отслеживается через `Coverage.py`.
* Запуск тестов локально:

```
docker compose exec web python manage.py test
```

## Запуск приложения
В терминале из корня проекта выполните команду сборки и запуска всех сервисов:

```
docker compose up --build
```

Приложение автоматически выполнит миграции базы данных (`python manage.py migrate`), 
создаст необходимые тома для статики и запустит веб-сервер вместе с воркерами `Celery`.

Полезные команды:

* Посмотреть логи конкретного сервиса: `docker compose logs -f web`
* Выполнить команду внутри контейнера: `docker compose exec web python manage.py createsuperuser`
* Полная остановка и удаление томов (очистка БД): `docker compose down -v`
